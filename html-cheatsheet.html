HTML 标签速查表

标签 说明 示例
文档结构
<html>根元素，包含整份文档<html lang="zh-CN">
<head>元信息，不会显示在页面上<head>…</head>
<body>页面可见内容<body>…</body>
<div>块级容器，用于布局分组<div class="box">…</div>
<span>行内容器，用于局部样式<span style="color:red">红字</span>
文本
<h1> ~ <h6>标题，数字越大级别越低<h1>标题</h1>
<p>段落<p>一段文字</p>
<br>换行（单标签）第一行<br>第二行
<hr>水平分隔线（单标签）<hr>
<strong>重要内容，默认加粗<strong>注意</strong>
<em>强调，默认斜体<em>强调</em>
列表
<ul>无序列表<ul><li>项</li></ul>
<ol>有序列表<ol><li>项</li></ol>
<li>列表项，放在 ul / ol 内<li>列表项</li>
<dl> <dt> <dd>描述列表：术语 + 解释<dt>HTML</dt><dd>超文本标记语言</dd>
链接与媒体
<a href="">超链接<a href="https://example.com">链接</a>
<img src="" alt="">图片（单标签），alt 为替代文字<img src="a.png" alt="图片">
<video> / <audio>视频 / 音频<video src="a.mp4" controls></video>
<iframe src="">嵌入另一个页面<iframe src="a.html"></iframe>
表格
<table>表格容器<table>…</table>
<tr>表格行<tr>…</tr>
<th>表头单元格，默认加粗居中<th>姓名</th>
<td>普通单元格<td>张三</td>
<thead> / <tbody>表头 / 表体分组<thead>…</thead>
表单
<form>表单容器<form action="/submit" method="post">…</form>
<input>输入控件，type 决定形态<input type="text" placeholder="请输入">
<textarea>多行文本输入<textarea rows="4"></textarea>
<select> <option>下拉选择<select><option>A</option></select>
<button>按钮<button type="submit">提交</button>
<label>表单说明，可通过 for 关联控件<label for="name">姓名</label>
语义化标签
<header>页头区域<header>…</header>
<nav>导航区域<nav>…</nav>
<main>页面主体内容（每页一个）<main>…</main>
<section>按主题划分的区块<section>…</section>
<article>独立完整的内容单元<article>…</article>
<footer>页脚区域<footer>…</footer>
<head> 中常用
<meta charset>字符编码，防止中文乱码<meta charset="UTF-8">
<meta viewport>移动端适配<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>浏览器标签页标题<title>页面标题</title>
<link>引入外部资源，如 CSS<link rel="stylesheet" href="style.css">
<script>引入或内联 JavaScript<script src="app.js"></script>
